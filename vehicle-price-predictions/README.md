This project predicts the selling price of used cars based on some of the car's features.
The Jupyter-notebook above contains the code used to create the machine learning model as well as a simple way to try out the model.

For non-programmers you can test this machine learning model by opening up the notebook and jumping straight to the Try It Out! section which is about the ending part of the notebook.
Follow the instructions given there and enjoy!
